Guide d'utilisation du site

Quelques repères pour naviguer sur le site KAYA COMPUTING et trouver rapidement ce dont vous avez besoin.

Navigation sur le site

Le site est organisé en trois pages principales, accessibles depuis le menu en haut de chaque page :

  • Accueil — présentation générale de KAYA COMPUTING, nos trois expertises et les questions fréquentes.
  • Services — détail de chaque prestation, comparatif site web / application mobile, et nos formules d'engagement.
  • Contact — formulaire de demande de projet et l'ensemble de nos canaux directs.

Comment nous contacter

Plusieurs moyens sont à votre disposition, visibles en haut et en bas de chaque page :

  • WhatsApp — pour une réponse rapide, via le bouton présent dans l'en-tête du site.
  • E-mail — contact@kayacomputing.sn, pour une demande plus détaillée.
  • Formulaire de contact — sur la page Contact, pour décrire précisément votre projet.

Étapes pour démarrer un projet

  1. Consultez la page Services pour identifier si votre besoin est un site web, une application mobile, ou les deux.
  2. Contactez-nous via le canal de votre choix (WhatsApp, e-mail ou formulaire).
  3. Nous vous transmettons un devis détaillé, adapté à la complexité et aux délais de votre projet.
  4. Une fois le cadrage validé, nous démarrons le projet selon un planning précis.

Astuces pratiques

  • Un bouton apparaît en bas à droite de l'écran dès que vous faites défiler une page : il permet de remonter instantanément en haut.
  • Sur mobile, le menu de navigation se replie derrière l'icône ☰ en haut à droite de l'écran.
  • Le lien vers la politique de confidentialité se trouve en bas de chaque page, dans le pied de page.

Besoin d'aide supplémentaire ?

Si votre question n'est pas couverte par ce guide, n'hésitez pas à nous écrire directement depuis la page Contact.
